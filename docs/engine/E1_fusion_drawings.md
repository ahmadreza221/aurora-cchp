## ۳. نقشه‌ها

### ۳-۰. ساخت سند نقشه (دستی، برای هر نقشه ۱۰ ثانیه)
1. سند منبع را از Data Panel باز کنید (جدول بخش ۱).
2. `File → New Drawing → From Design`؛ گزینه‌ها: Standard **ISO**، Units **mm**، Sheet Size **A3**؛ Contents: Full Assembly؛ OK. فیوژن سند نقشه می‌سازد و فرمان Base View را باز می‌کند؛ Esc بزنید (نمای اول را هم اسکریپت می‌گذارد) یا نمای اول را خودتان بگذارید.
3. سند را با نام جدول زیر ذخیره کنید؛ سپس اسکریپت MCP (ماژول بخش ۲) نماها، ابعاد، داتوم‌ها، قاب‌ها، جدول یادداشت و PDF را اضافه می‌کند. *(یک‌بار برای همیشه: اگر از همین نقشه `Save As Template` بگیرید، از آن به بعد `new_drawing()` با `FromTemplateBaseDocumentType` می‌تواند سندها را خودش بسازد.)*

## ۴. CAM (Manufacture)، §۷ مشخصات ساخت

API `adsk.cam` ستاپ و عملیات را بدون UI می‌سازد: `cam.setups.createInput(TurningOperation)` + `models` (بدنه‌ها) → `setups.add`؛ `setup.operations.createInput('turning_face' | 'turning_profile_finishing' | 'turning_single_groove' | …)` + `tool` از کتابخانهٔ «Turning Tools (Metric)» (`CAMManager.libraryManager.toolLibraries`) + پارامترها (`frontHeight_mode/offset`, `backHeight_*`, `outerRadius_*`, `innerRadius_*`, `turningMode`, `grooving`, `xStockToLeave`, `tool_surfaceSpeed`, `tool_feedCuttingRel`) → `operations.add` → `cam.generateToolpath(ops)`. ماژول کمکی: **`fusion/GR180_E1_CAM/GR180_E1_CAM.py`** (`cam_product`, `tool_libraries`, `find_tools`, `turning_setup`, `operation`, `report`). دو درس عملی: (۱) `itemByProductType('CAMProductType')` پیش از فعال‌شدن Manufacture خطا می‌دهد (نه null) → workspace `CAMEnvironment` را فعال کنید؛ (۲) **مدل ستاپ تراش باید فقط بدنه‌های دوّار باشد** (`disc` + `shaft`؛ نه ۲۹ پرهٔ B-spline): با پره‌ها «No valid turning profile found» می‌دهد. پره‌ها در شبیه‌سازی برخورد باید جداگانه (به‌عنوان fixture یا با مدل کامل) کنترل شوند.
