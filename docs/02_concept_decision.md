## ۲. داده‌های جدید که تصمیم را عوض کرد

- **مشکل C1 حل شد.** در نقشهٔ `GR180 Compressor.pdf` عرض خروجی پروانه **b2 = 6.48 mm** است (ضخامت لبهٔ دیسک 1.2 و فاصلهٔ نوک تا پشت پروانه 7.68).
  - مدل CAD عدد را اشتباه خوانده بود (2.9).
  - نسبت کانال دیفیوزر به خروجی پروانه حالا 7.0/6.48 = 1.08 است که درست است.
  - ⚠️ موقعیت محوری پروانه نسبت به intake و دیفیوزر باید در CAD از نو چیده شود.
- **داده‌های تست واقعی** (`GR180 turbine notes.pdf`):

  | دور (rpm) | تراست | EGT |
  |---|---|---|
  | 100k | 115 N | 560 °C |
  | 110k | 145 N | 620 °C |
  | 117k | 178 N | 680 °C |
  | 119k | 186 N | 720 °C |

  - EGT عادی 550 تا 650 °C است و حداکثر 730 °C.
  - مدل سیکل با η_c ≈ 0.70 و η_t ≈ 0.80 با این داده‌ها جور است: **هوا ~0.40 kg/s و PR ~3.2**.

## ۳. مقایسهٔ معماری‌ها (طراحی در ISA 15 °C، هوا 0.40 kg/s)

| # | معماری | برق خالص | η برق | حرارت CHP | η کل | متان |
|---|---|---|---|---|---|---|
| S0 | هستهٔ فعلی + FPT + PMG (سیکل ساده) | 23.0 kW | 7.2 % | 214 kW | 74 % | 32 Nm³/h |
| S1 | + recuperator ε 0.85 | 19.9 kW | 15.6 % | 82 kW | 79 % | 12.8 Nm³/h |
| S2 | + recuperator ε 0.90 | 20.9 kW | 17.8 % | 73 kW | 80 % | 11.8 Nm³/h |
| **S3** | **هدف: هستهٔ تنظیم‌شده (η_c .73، η_t .82) + FPT 0.78 + recup 0.90، TIT 850 °C** | **26.4 kW** | **21.7 %** | **72 kW** | **81 %** | **12.2 Nm³/h** |
| S4 | همان، تک‌محوره (Capstone-type) | 28.1 kW | 22.7 % | 72 kW | 81 % | 12.4 Nm³/h |
| S5 | بدبینانه: هستهٔ فعلی، FPT 0.68، recup 0.85، TIT 800 °C | 14.3 kW | 11.9 % | 80 kW | 78 % | 12.1 Nm³/h |

- همهٔ اعداد شامل این تلفات‌اند: ژنراتور 95 %، اینورتر 96 %، کمپرسور گاز و تجهیزات کمکی ~1.5 kW، و 2 % تلفات حرارتی بدنه.
- **کلید رسیدن به 20 % فقط recuperator است.** بدون آن سقف ~7 % است.
- **کلید رسیدن به > 20 kW**:
  - کار در 117 تا 120 هزار دور
  - رفع مشکلات هسته (لقی‌ها و تراز محوری پروانه)
  - بازده FPT ≥ 0.75
- راندمان کل > 55 % در هر حالتی با مبدل آب گرم به‌راحتی رد می‌شود (75 تا 81 %).

## ۴. پیشنهاد: S3 — «GR180 + توربین قدرت آزاد + ژنراتور پرسرعت + recuperator + CHP»

```
Air filter/silencer -> Intake -> GR180 compressor (PR 3.2, 0.40 kg/s, 117-120k rpm) -> diffuser -> collector
 -> RECUPERATOR cold side (171 C -> ~600 C) -> new gas combustor -> NGV -> GG turbine (drives compressor only)
 -> interduct -> FPT NGV -> FREE POWER TURBINE (~55-65k rpm) ==shaft==> HS PMG ~30 kW (water-cooled)
 -> RECUPERATOR hot side (645 C -> ~275 C) -> exhaust/water HX (-> 90 C stack, ~72 kW hot water) -> stack
PMG (1-2 kHz) -> SiC active rectifier -> DC 700-750 V -> 3-phase inverter 400 V / 50 Hz (+ grid protection)
```

**چرا FPT و نه تک‌محوره (S4)؟** S4 فقط حدود 1 % راندمان بیشتر می‌دهد، ولی:
- ژنراتور را روی شفت 120k با یاتاقان 608 می‌گذارد. شبیه‌سازی روتور نشان داد مود بحرانی را به 118 تا 127 هزار دور می‌آورد.
- توربین جدید و پربارتری لازم دارد.

در مقابل، FPT:
- **روتور هسته را دست‌نخورده نگه می‌دارد** (که تست‌شده است).
- ژنراتور در ~60k با یاتاقان مستقل و دور بهینه کار می‌کند.
- عیبش: ژنراتور نمی‌تواند هسته را استارت کند، پس استارتر هسته می‌ماند (برقی قوی‌تر، یا هوای فشرده از سوراخ M5 airstart).

**گیربکس:** در این معماری لازم نیست. PMG حدود 30 kW در 60k rpm (گشتاور ~4.8 N·m، روتور ~Ø50×60 با غلاف کربنی) مستقیم روی شفت FPT قرار می‌گیرد.

## ۵. تغییرات لازم در هر زیرسیستم

| زیرسیستم | وضعیت | کار لازم |
|---|---|---|
| ورودی هوا | جدید | فیلتر، صدا‌خفه‌کن، سنسور دمای هوا |
| کمپرسور و دیفیوزر | نگه‌داری با اصلاح | b2=6.48 و تراز محوری با intake/دیفیوزر طبق نقشه، بالانس، تپ فشار P2 (سوراخ آزاد پره) |
| بدنه (casing) | **بازطراحی** | مخزن تحت فشار با خروجی به recuperator و ورودی برگشت. قوطی CV470 0.3 mm کافی نیست. |
| محفظهٔ احتراق | **بازطراحی** | هوای ورودی ~600 °C به خودسوزی متان (~580 °C) نزدیک است، پس لوله‌های vaporiser (پیش‌مخلوط) کنار می‌روند. جایگزین: انژکتورهای گاز diffusion/swirl، لاینر Hastelloy-X/Inconel 600، توزیع جدید سوراخ‌ها. |
| NGV و توربین هسته | اصلاح | لقی نوک 0.25 (v13)، نشیمن توربین (C4)، shroud کامل، کاهش دور برای عمر |
| یاتاقان هسته | **سیستم روغن جدید** | مدار بسته شامل پمپ، فیلتر، خنک‌کن و برگشت، به‌جای total-loss. برنامهٔ تعویض 608. |
| FPT | **جدید** | NGV با مساحت هم‌خوان، روتور محوری Ø~75 میانگین، شفت و یاتاقان هیبرید زاویه‌ای، تراست‌بالانس |
| ژنراتور PMG | **جدید** | ~30 kW در 60k، خنک‌کاری آبی (پیش‌گرم مدار CHP) |
| الکترونیک قدرت | **جدید** | یکسوساز فعال SiC، باس DC، اینورتر سه‌فاز 400 V، حفاظت شبکه (anti-islanding)، ترمز/dump resistor |
| recuperator | **جدید (بزرگ‌ترین قطعه)** | ~172 kW انتقال حرارت، ε 0.90، ~36 m² سطح (plate-fin یا primary-surface از SS347/Inconel 625)، ΔP ≤ 3 % هر طرف |
| مبدل آب گرم CHP | جدید | اگزوز 275 → 90 °C، ~72 kW، پمپ و شیر سه‌راهه |
| سوخت | **جدید** | بوستر گاز (≥ 4.5 barg)، فیلتر، رگولاتور، دو شیر قطع سری کلاس A، شیر تناسبی، سنسور فشار/دبی، نشت‌یاب |
| بدنهٔ کلی | جدید | حفاظ ترکیدن (containment)، عایق صوتی و حرارتی، تهویه |

## ۶. سنسورها و کنترل

| گروه | سنسورها |
|---|---|
| دور | N1 هسته (Hall فعلی)، N2 از فرکانس PMG + سنسور مستقل |
| دما | EGT هسته (۳ ترموکوپل)، TOT خروجی FPT، دمای دو طرف recuperator، روغن، سیم‌پیچ ژنراتور، آب رفت و برگشت، اتاقک |
| فشار | P2 کمپرسور، P بعد از recuperator، ΔP محفظه، فشار گاز قبل و بعد شیر، فشار روغن |
| ایمنی | ارتعاش (دو شتاب‌سنج: هسته و FPT)، تشخیص شعله (UV یا یونیزاسیون)، نشت گاز، E-stop |
| کنترل (ECU) | توالی استارت، گاورنر دور N1 و N2، محدودکنندهٔ EGT، کنترل بار از طریق گشتاور اینورتر، حفاظت سرج، trip و خاموشی ایمن |

## ۸. فازبندی

1. **هسته:** اصلاح CAD هسته طبق نقشه‌ها (b2، تراز، C3، C4، I2 و I3) + چک کامل تداخل + CFD و FEA هسته.
2. **سیکل نهایی:** انتخاب نقطهٔ طراحی (دور، TIT، ε)، meanline برای FPT، ابعاد PMG و recuperator.
3. **CAD ماژول‌ها:** FPT + PMG، بدنهٔ فشاری + collector، محفظهٔ جدید، recuperator، مبدل CHP. همه در همان اسکریپت پارامتری.
4. **سیستم‌ها:** سوخت، روغن، آب، برق، سنسورها و ECU، به‌همراه شبیه‌سازی گذرا.
5. **ساخت و تست:** اول هسته روی استند (کالیبره‌کردن مدل)، بعد FPT و بار، بعد recuperator و CHP.
