# نسخه‌ی B (GR180-STEAM): توربین گازی سیکل ساده + بویلر بازیاب + توربین بخار دوحالته

تاریخ: ۲۰۲۶-۱۰-۲۳ · تصمیم کاربر: گزینه‌ی ۴ دوحالته (extraction-condensing). **طرح فعلی (نسخه‌ی A، ریکوپراتوری) خط اصلی می‌ماند**؛ نسخه‌ی B خط دوم برای اتصال به شبکه با برق بیشتر است.
محاسبات: `sim/variant_b/vb_cycle.py` → `sim/variant_b/vb_results.json`.

## ۱. معماری

```
هوا → کمپرسور GR180 → E2-B محفظه‌ی احتراق (ورودی 165 °C) → E1 توربین هسته → E3 توربین قدرت + PMG ۱ → اینورتر ۱ ─┐
                                                                                     │ اگزوز ~600 °C            ├─ تابلوی مشترک → بارها / شبکه
                                                                                     ▼                          │
        B-HRSG بویلر بازیاب (سوپرهیتر، اواپراتور، اکونومایزر) → بخار 40 bar / 480 °C → B-ST توربین بخار + PMG ۲ → اینورتر ۲ ─┘
                                                              │ برداشت 0.8 bar → آب داغ 88/83 °C → چیلرهای جذبی SC10+SC5
                                                              │ هواگیر 1.3 bar
                                                              ▼ کندانسور 0.08 bar → برج خنک‌کن
        دودکش 172 °C → اکونومایزر آب گرم مصرفی 60 °C → 95 °C به هوا
```

**مشترک با نسخه‌ی A (بدون تغییر):** هسته‌ی v13A، E1 (توربین و NGV هسته)، E3 (توربین قدرت، یاتاقان‌ها، PMG ۳۰ kW، کلکتور اگزوز)، سیستم کنترل، باتری و اینورتر ۱.
TIT، نسبت فشار و دبی هوا همان نسخه‌ی A است، پس E1 و E3 در همان نقطه‌ی طراحی کار می‌کنند.

**تغییر یا جدید:**

| کد | زیرسیستم | جای چه چیزی |
|---|---|---|
| E2-B | محفظه‌ی احتراق برای ورودی سرد 165 °C و ~2.7 برابر سوخت (~6 g/s) | E2 |
| B-HRSG | بویلر بازیاب یک‌بارگذر (monotube) یا درام‌دار، 190 kW | E4 ریکوپراتور |
| B-ST | توربین بخار چندمرحله‌ای ~45 kW با برداشت، یا موتور بخار پیستونی | جدید |
| B-BOP | کندانسور، هواگیر، پمپ تغذیه، تصفیه‌ی آب (RO + رزین)، مبدل آب داغ، اکونومایزر دودکش، لوله‌کشی بخار | جدید |
| B-EL | PMG ۲ + یکسوساز + اینورتر ۲، حفاظت اتصال به شبکه | جدید |

## ۳. تصمیم‌های اولیه

1. **بدون گیربکس.** هر دو توربین ژنراتور پرسرعت مستقیم (PMG) و اینورتر دارند؛ اتصال به شبکه (ضریب توان، ضد جزیره‌ای، هم‌زمانی) با اینورتر انجام می‌شود.
2. **دو گزینه برای B-ST** که باید مقایسه شود: (الف) توربین بخار چندمرحله‌ای پرسرعت با PMG (طراحی خودمان، مثل E3)؛ (ب) موتور بخار پیستونی آماده با ژنراتور معمولی 1500 rpm (سازنده‌ی آلمانی Spilling در این رنج کار می‌کند — تأیید شود). موتور پیستونی در این اندازه راندمان ایزنتروپیک بهتر و نگهداری ساده‌تری دارد ولی برداشت بخار در آن محدودتر است.
3. **HRSG یک‌بارگذر (monotube)** ترجیح دارد: آب داخل آن کم است (ایمن‌تر روی بام، راه‌اندازی سریع، بدون درام). نیاز به آب خیلی خالص دارد.
4. **محفظه‌ی احتراق E2-B** باید دوباره ابعاد بگیرد: هوای ورودی سرد، سوخت ~6 g/s، انژکتورها و سوراخ‌ها. تعداد انژکتورها همان ۷ می‌ماند (قید لرزش پره‌ی E1).

## ۴. ریسک‌ها و موارد باز

- **دیگ بخار 40 بار روی بام:** مخزن تحت فشار؛ بازرسی و گواهی، شیرهای اطمینان، تخلیه‌ی اضطراری. وزن HRSG + توربین بخار + کندانسور + آب باید با بام چک شود (نسخه‌ی A حدود 7 تن است).
- **کیفیت آب:** آب شهر TDS 400؛ برای بویلر یک‌بارگذر RO دو مرحله + رزین مخلوط (یا EDI) + هواگیر + کنترل شیمیایی لازم است.
- **توربین بخار 45 kW** کالای کمیاب است؛ طراحی خودمان یعنی یک توربین چندمرحله‌ای پرسرعت دیگر با یاتاقان، آب‌بندی بخار و PMG.
- **برج خنک‌کن** در حالت چگالشی 144 kW اضافه دفع می‌کند؛ برج فعلی باید بزرگ‌تر شود.
- **بهینه‌سازی بعدی:** پیش‌گرمایش کندانسه در دودکش به جای آب گرم مصرفی (چند کیلووات برق بیشتر در حالت چگالشی)؛ فشار برداشت متغیر بر اساس دمای لازم چیلر.

## ۵. گام‌های بعدی

1. B-HRSG: طراحی حرارتی (سطوح، لوله‌ها، افت فشار سمت گاز) + مدل FreeCAD + BOM.
2. B-ST: مقایسه‌ی توربین چندمرحله‌ای با موتور بخار پیستونی؛ طراحی یا انتخاب + مدل + BOM.
3. E2-B: ابعاد محفظه‌ی احتراق برای ورودی سرد (پس از merge شاخه‌ی E2).
4. B-BOP و جانمایی روی بام، چک وزن و ایمنی.
5. B-EL: اینورتر دوم و حفاظت اتصال به شبکه.
