# GR180-CCHP — فهرست ورودی/خروجی (I/O list)

تاریخ: ۲۰۲۶-۱۰-۲۱ · **فایل تولیدشده** از `docs/electrical/calc/io_list.py` (منبع واحد). نسخهٔ CSV: [`02_io_list.csv`](02_io_list.csv). معماری و بردها: [`00_electrical_control_architecture.md`](00_electrical_control_architecture.md)؛ آستانه‌های trip: [`03_control_philosophy.md`](03_control_philosophy.md)؛ کابل‌ها: [`05_cable_schedule.md`](05_cable_schedule.md).

**قواعد عمومی**

- همهٔ ترموکوپل‌ها **ungrounded** هستند (جلوگیری از حلقهٔ زمین با AFE غیرایزولهٔ STM32F373)؛ اتصال TC به مس فقط روی ترمینال‌های ایزوترمال B2، کنار CJC.
- سیگنال‌های 4–20 mA از B2 تغذیهٔ حلقه می‌گیرند (24 V محدود‌شده با PTC + TVS)؛ مقاومت شانت 50 Ω دقیق 0.1 %.
- تجهیزات داخل ناحیهٔ گاز در صورت طبقه‌بندی Zone 2 (IEC 60079-10-1) باید **Ex ec / Ex nA** یا ATEX Cat 3 باشند؛ هدف طراحی تهویه، ناحیهٔ «NE» است.
- «role»: C کنترل، P حفاظت (ارجاع به جدول trip)، M پایش/life counter.
- مکان: `R-ENG` = بام: ناحیهٔ موتور (داغ)؛ `R-GAS` = بام: ناحیهٔ گاز؛ `R-AIR` = بام: ورودی هوا؛ `R-CHP` = بام: ناحیهٔ آب/CHP؛ `R-ELC` = بام: تابلوی RP-1 روی اسکید؛ `R-ROOF` = بام: بیرون اسکید؛ `ER` = داخل: اتاق برق و باتری؛ `HALL` = داخل: سالن / تابلوی شرکت.
